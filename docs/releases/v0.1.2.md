# agent-contracts v0.1.2

`v0.1.2` turns scoring from a console readout into a public artifact path for
the Shadow Agent Reliability Index.

## Added

- `agent-contracts score --output-json` for full machine-readable score payloads.
- `agent-contracts score --output-markdown` for commit-ready public scorecards.
- `agent-contracts score --output-badge-json` for Shields endpoint badges.
- CI upload of `agent-reliability-score.json`, `AGENT_RELIABILITY_SCORE.md`, and
  `agent-reliability-badge.json`.
- Seed self-score artifacts for `impartshadow/agent-contracts`: `95/100`, grade
  `A`.

PYTHONPATH=. pytest -q
